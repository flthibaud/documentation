## Comment ce rayon s'organise

À plat tant que le rayon est petit, puis un sous-dossier par domaine — repris
automatiquement dans la sidebar :

```
technique/
├── index.mdx
├── aide-memoire-git.md
├── bases-de-donnees/
│   └── index-postgres.md
├── outils/
│   └── docker-compose.md
└── decisions/
    └── 001-choix-du-framework.md
```

## Types de fiches

- **Aide-mémoire** — commandes ou raccourcis, peu de prose.
- **Procédure** — étapes ordonnées, prérequis, vérification finale.
- **Décision** — contexte, options écartées, décision, conséquences.
